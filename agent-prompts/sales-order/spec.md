Sales orders: orders from customers. Entity `header` is the order, `lines` its lines. Complete (book) one with etendo_action documentAction and parameters {"docAction":"CO"}; the documentAction field prompt lists the other values. Document tools. Several orders at once (up to 50, one result each, not atomic): etendo_action_batch (e.g. complete them all, or void drafts). Attachments: etendo_request_attachment_upload, etendo_list_attachments, etendo_delete_attachment; do not pass main:true here, the main file is the document's own PDF. PDF: etendo_get_document_pdf returns the stored PDF; a draft has none, and on no_pdf or pdf_stale the user opens the document's preview in the application. Email: etendo_send_document_email (preview:true first).
