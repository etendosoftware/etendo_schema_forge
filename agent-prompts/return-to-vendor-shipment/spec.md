Returns to a vendor (Return to Vendor Shipment): goods sent back to a supplier against completed goods receipts, optionally refunded with a rectificative purchase invoice. Entity `returnToVendorShipment` is the header, `returnToVendorShipmentLine` the lines. Two ways to create one. FAST PATH, from one receipt: etendo_action `createPurchaseReturn` on the completed goods receipt (spec goods-receipt, entity goodsReceipt) creates the return already linked to it, in DRAFT; omit `lines` to return everything still returnable, or send {lines:[{lineId, returnQuantity}]} to return exactly those (the answer lists each created line with its sourceLineId). THE UI's FLOW, which also lets one return take lines from several receipts of the same vendor, in this order: (1) create the header with etendo_create on `returnToVendorShipment`: businessPartner and partnerAddress are the fields to send — warehouse, movementDate, document type and currency are defaulted — and etendo_schema with view:"create" (or etendo_defaults) is the authority on what a create needs; (2) etendo_action `availableReceipts` with {businessPartner} and id "_" lists the vendor's completed receipts that still have quantity to return; (3) `availableReceiptLines` with {receiptId, businessPartner} and id "_" lists that receipt's returnable lines (movementQuantity is what is still returnable); (4) `importReceiptLines` on the new header id with {lines:[{sourceLineId, returnQuantity}]} adds the return lines (repeat for each receipt); (5) confirm the return with the DocAction button (action documentAction, docAction CO); (6) `rectifiableInvoices` on the header id lists the invoices it can rectify (and hasReturnInvoice); (7) `createReturnInvoice` on the header id with {originInvoices:[...]} creates, links and confirms the rectificative invoice. Return lines exist only by import: there is no manual line entry with a product. A return can never take more than what is still returnable of a receipt line: what other non-voided returns of that line hold, drafts included, is already taken. Asking for more answers 422 returnQuantityExceedsAvailable (naming the product, the requested and the available quantity) and creates nothing, including when the quantity of an existing return line is edited above it. etendo_schema with view:"actions" returns each action's parameters.
