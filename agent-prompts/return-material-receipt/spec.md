Customer returns (Return Material Receipt): goods a customer sends back against a completed goods shipment, optionally refunded with a rectificative sales invoice. Entity `returnMaterialReceipt` is the header, `returnMaterialReceiptLine` the lines. The flow is the UI's, in this order: (1) create the header with etendo_create on `returnMaterialReceipt`: businessPartner and partnerAddress are the fields to send — warehouse, movementDate, document type and currency are defaulted — and etendo_schema with view:"create" (or etendo_defaults) is the authority on what a create needs; (2) etendo_action `availableShipments` with {businessPartner} and id "_" lists the customer's completed shipments that still have quantity to return; (3) `availableShipmentLines` with {shipmentId} and id "_" lists that shipment's returnable lines; (4) `importShipmentLines` on the new header id with {lines:[{sourceLineId, returnQuantity}]} adds the return lines; (5) confirm the return with the DocAction button (action documentAction, docAction CO); (6) `rectifiableInvoices` on the header id lists the invoices it can rectify (and hasReturnInvoice); (7) `createReturnInvoice` on the header id with {originInvoices:[...]} creates, links and confirms the rectificative invoice. etendo_schema with view:"actions" returns each action's parameters.
