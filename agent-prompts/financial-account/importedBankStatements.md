The `importedBankStatements` entity is a bank statement (FIN_BankStatement) of a financial account; `bankStatementLines` are its lines. Read both with etendo_list/etendo_get. Generic create/update/delete on both entities is refused with 405: change a statement with the `bank-statements` spec actions — `etendo_action {spec:"bank-statements", entity:"bank-statements", id:<statement id>, action:"updateStatement"|"processStatement"|"reactivateStatement"|"deleteStatement"}` — and create one with `createStatement`/`importStatement` (id = the financial account). Catalogue: `etendo_schema({spec:"bank-statements", view:"actions"})`.
