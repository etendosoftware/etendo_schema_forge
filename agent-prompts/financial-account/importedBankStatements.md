The `importedBankStatements` entity is a bank statement (FIN_BankStatement) of a financial account; `bankStatementLines` are its lines. Read both with neo_list/neo_get. Change a statement only with the named actions `update`, `process`, `reactivate` and `delete` (`neo_action`, id = the statement); generic create/update/delete on both entities is refused with 405, and new statements are created on the `account` entity. Parameters: see neo_schema({view:"actions"}).
