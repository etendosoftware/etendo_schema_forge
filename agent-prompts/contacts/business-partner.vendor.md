Whether the contact is a vendor/creditor. Always send it, together with customer, on create: read the contact's business partner category (the one you send in businessPartnerCategory, or the business-partner-category record with default true when you send none) and send vendor = its etgoIsvendor and customer = its etgoIscustomer, unless the user explicitly asked for a different type, in which case send what the user asked. Do not rely on the server to fill it from the category: depending on the server configuration an omitted value may get the column default (vendor false) instead, so a vendor would be saved as a customer. On update, when you change businessPartnerCategory, send customer and vendor matching the new category in the same request unless the user asked otherwise. A contact should end up with customer or vendor true; if the category sets neither, ask the user which type the contact is.
