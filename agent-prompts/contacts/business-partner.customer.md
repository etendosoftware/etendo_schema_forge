Whether the contact is a customer. Usually omit it on create: when it is not sent, the server inherits it from the contact's business partner category (the category's etgoIscustomer flag; the default category when businessPartnerCategory is omitted too). Send it only to override that inherited value. On update, changing businessPartnerCategory without sending customer or vendor re-applies BOTH flags from the new category; send either flag in the same request to decide the type yourself. A contact must end up with customer or vendor true, otherwise the save is rejected.
